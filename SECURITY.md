# Security Policy

BraginCAD обрабатывает DWG локально и не запрашивает доступ в Интернет. DWG является сложным бинарным форматом; открывайте файлы только из доверенных источников и используйте актуальную версию приложения.

О найденной уязвимости сообщайте владельцу репозитория приватным способом через GitHub Security Advisories. Не публикуйте рабочий exploit в открытом issue до исправления.
