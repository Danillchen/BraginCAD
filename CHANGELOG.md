# Changelog

## 1.0 — 2026-10-12

### Просмотр и инструменты

- добавлен выбор линии и основных геометрических объектов с просмотром типа, слоя, длины и типа линии;
- выбранный объект подсвечивается на чертеже, выбор снимается касанием пустого места;
- цвет можно изменить только у выбранного объекта, не затрагивая весь слой;
- исправлено разделение жестов масштабирования и вращения, настройки единиц измерений наследуются новыми измерениями.

### Обновления и интерфейс

- в настройках добавлена проверка новых версий через официальный GitHub-репозиторий `Danillchen/BraginCAD`;
- добавлена прямая ссылка на APK последнего релиза;
- обновлены иконки и экран настроек, исправлен splash-экран светлой темы.

## 0.2.0 — 2026-09-16

### Цвета и отображение

- добавлены исходные цвета слоёв DWG, цветной/монохромный режим и изменение цвета отдельного слоя;
- добавлен выбор фона чертежа и автоматическая коррекция слабоконтрастных линий;
- увеличены подписи измерений и добавлен выбор их размера в настройках.

### Инструменты и файлы

- добавлено вынесение точки на заданные расстояние и угол с последующим просмотром X/Y/Z;
- исправлены независимые цвета нескольких измерений и отображение координаты Z;
- внешние DWG (включая открытые из почты) сохраняются во внутреннем хранилище и надёжно открываются из «Недавних».

### Проверка

- universal APK содержит native LibreDWG для `armeabi-v7a`, `arm64-v8a`, `x86` и `x86_64`;
- полный набор из 11 реальных DWG проверен на Android 16 без native/AndroidRuntime crash.

## 0.1.1 — 2026-08-13

### Совместимость

- добавлены настоящие native-сборки BraginCAD/LibreDWG для `armeabi-v7a` и `x86`;
- universal APK теперь поддерживает `armeabi-v7a`, `arm64-v8a`, `x86` и `x86_64`;
- исправлена установка на устройствах с 32-битным Android userspace, включая часть телефонов с 64-битным процессором MediaTek.

## 0.1.0 — 2026-08-10

Первый публичный preview BraginCAD.

### DWG viewer

- локальная LibreDWG/NDK-цепочка для `arm64-v8a` и `x86_64`;
- слои, SAF, recent files, pan, zoom и fit;
- поддержка BLOCK/INSERT, TEXT/MTEXT, dimensions и основных CAD-примитивов;
- метрики graphical и visible graphical coverage;
- viewport-aware HATCH renderer с LOD и work budget.

### Измерения

- Distance, Area и Coordinate;
- Endpoint snap и DWG units;
- точность 0–4 знака;
- session-only overlays с выбором, удалением одной отметки и Delete All.

### Mobile UX

- Material 3, светлая и тёмная темы;
- единый минималистичный brand asset;
- universal debug APK для телефона и эмулятора.
